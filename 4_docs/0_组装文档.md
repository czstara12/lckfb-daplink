# 开始组装

1. 拿出扩展板和屏幕。![image-20240612184800780](./images/image-20240612184800780.png)

2. 将屏幕FPC排线的金手指朝上插入扩展板的座子里面，插到位置后锁紧。

![image-20240612192124184](./images/image-20240612192124184.png)

3. 拿出3D打印的上壳和一体按钮。![image-20240612185113671](./images/image-20240612185113671.png)

4. 将一体按钮如图所示塞入上壳中。![image-20240612185205591](./images/image-20240612185205591.png)

5. 将屏幕从上壳中间的凹槽中穿过。![image-20240612185405428](./images/image-20240612185405428.png)

6. 拿出4颗【M3x10】铜柱和四颗【M3x8 头4.0】沉头螺丝。![image-20240612185631966](./images/image-20240612185631966.png)

7. 铜柱在下，沉头螺丝在上，用十字螺丝刀将扩展板和上壳固定，固定好后如图右所示将屏幕塞入上壳凹槽内即可。![image-20240612185855640](./images/image-20240612185855640.png)

8. 拿出GD32版本的天空星。![image-20240612185936141](./images/image-20240612185936141.png)

9. 按下图所示插入扩展板的双排母内。![image-20240612190027443](./images/image-20240612190027443.png)

10. 将下壳盖到天空星上面。![image-20240612190126970](./images/image-20240612190126970.png)

11. 在四个螺丝孔内放入四颗【M3x8 头4.0】沉头螺丝，并用螺丝刀拧紧。![image-20240612190321722](./images/image-20240612190321722.png)

12. 将多功能调试器翻面，拿出正面面板。![image-20240612190531208](./images/image-20240612190531208.png)

13. 撕掉屏幕的保护膜，撕掉面板的背胶保护膜。![image-20240612190643587](./images/image-20240612190643587.png)

14. 将面板嵌入上壳的凹槽内，注意对齐按钮孔位。![image-20240612190745032](./images/image-20240612190745032.png)

15. 按照之前操作，撕掉面板背胶保护膜后一并安装侧面面板。![image-20240612191203407](./images/image-20240612191203407.png)

16. 拿出防滑脚垫，将四颗脚垫按入下壳的固定孔位中。![image-20240612191402218](./images/image-20240612191402218.png)

17. 拿出已经写入芯片下载算法和待下载固件的TF卡。![image-20240612191523456](./images/image-20240612191523456.png)

18. 将TF卡插入卡槽中。![image-20240612191607908](./images/image-20240612191607908.png)

19. 拿出插拔式接线端子。![image-20240612191700006](./images/image-20240612191700006.png)

20. 插入PD输出口方便我们后期接线使用。![image-20240612191744928](./images/image-20240612191744928.png)

21. 装好后的实物图如下所示：![image-20240612191912833](./images/image-20240612191912833.png)
